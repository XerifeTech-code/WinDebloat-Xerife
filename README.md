# WinDebloat-Xerife
Se o seu computador está lento, travando ou demorando uma eternidade para iniciar, a culpa provavelmente não é do seu hardware.  O seu computador só está lento porque a Microsoft instala, de forma silenciosa, dezenas de aplicativos ocultos e serviços de telemetria que você provavelmente nem sabia que existiam — e que muito menos utiliza.  .
